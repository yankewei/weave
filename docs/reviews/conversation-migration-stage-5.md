# 第 5 阶段 code review

范围：直接切换私有持久对话、web 异步提交和快照订阅、分页、提案处理、nginx / compose 路由，以及移除历史导入。

## 已检查并修复

- 首次读取的分页游标原先在 React state updater 执行前被 ref 标志覆盖，导致无法加载更早消息。改为按已有 conversation state 判断，新增分页与快照合并回归测试。
- 断线期间消息超过一个快照窗口时，旧游标会跳过中间消息；新增窗口衔接判断，从新游标向前补页，同时保留已加载内容。
- 分页参数统一使用 agent 契约中的 `cursor`，保留已加载消息及其游标，不使用 SSE 事件游标。
- 接收状态已通过读取修复、POST 的失败响应却稍后到达时，不再把已接受的消息误报为失败。
- POST 超时或代理失败可能掩盖已接受的输入。发送前保存 user/project 隔离的 requestId 与正文，显式重试复用原值；刷新不自动重发。PHP 增加 inputStatus，允许读取时明确修复接收状态。
- 旧 POST SSE 有整个生成的 70 秒超时。删除旧传输，GET SSE 使用心跳空闲检测，断连退避重连；卸载取消读取，不取消生成。解析支持跨字节 UTF-8 和 CRLF，finally 释放 reader。
- 终态不代表 PHP 已完成提案对账。syncStatus pending 继续轮询；待确认提案和未同步执行禁用新输入。
- 同项目不同成员原先受项目唯一约束阻挡。新增迁移 014 改为项目与所有者唯一，测试同项目两个私有对话及互相不可读。
- 权限失效后停止重连并清除当前消息视图，避免继续展示已撤销权限的私有正文。
- 迁移 011–013 保持不变；不清空实际数据库。历史导入接口、运行模式和文档状态全部移除，旧源码清理留给下一阶段。
- 测试桥接进程的 stdin 等待会受超时影响；改为等到 EOF 或显式退出信号，退出仍运行临时 schema 与子进程清理。
- web 测试脚本固定 `NODE_ENV=test`，避免外部 `NODE_ENV=production` 让 React 使用生产构建、缺失 `act` 而使新增 hook 测试全部失败。

## 验证

- PHPStan 与 PHPUnit：52 个测试通过，包含同项目私有归属、接收恢复、提案幂等、会话和成员撤权。
- agent 真实进程测试：10 个通过，包含重启、迟到请求封存、断连不取消生成、游标分页与删除导入路由。
- 浏览器：隔离环境注册、从首页建项目并发送、刷新恢复提案、确认生成 DEV-1、右侧待办与统计更新均已验证。
- web：SSE 分块解析与 hook 生命周期回归覆盖超时重试、刷新不重发、按用户隔离、重连和分页合并。
- `pnpm test:cutover`：真实 PHP + Pi Durable + 受控模型，隔离 PostgreSQL schema 和临时 SQLite。验证重复输入、断开订阅、终态对账、提案确认与重复确认只生成一个正式任务。

本阶段交付运行路径切换；没有执行实际数据库迁移或线上发布。legacy 目录、迁移镜像与旧表仍需下一阶段清理。
