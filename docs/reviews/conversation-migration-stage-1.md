# 第 1 阶段 review

范围：`docs/conversation-migration.md`、ADR 0002/0004 和 README；按当前 Pi Durable 1.4.0 的文档与类型声明核对，不涉及生产数据操作。

## 发现与修复

- P1：历史导入没有独立的完成接口，无法判断最后一个批次是否丢失，存在部分历史导入后接受新输入的风险。补充顺序、offset、重复 UUID 校验、消息总数与链式内容摘要；封存成功才允许正常模式接收输入，导入模式禁止生成。
- P1：契约要求生成终态后读一次 PHP，但两套存储非原子读取，提案结果可能尚未对账完成，页面会错过待确认提案。补充 PHP `syncStatus`，完成对账前继续轮询；不能把一次读取不到提案视为本次无提案。
- P2：映射创建与 admission 封存只列出路径，没有请求字段与冲突语义，无法验证归属绑定或拒绝迟到请求。补充归属 UUID、admission 绑定与返回结果。

## 结论

上述问题已修复，可进入第 2 阶段。第 2 阶段的模型工具、PHP 终态同步和浏览器切换仍不在本阶段内；必须维持 nginx 当前代理，不提前切换。
