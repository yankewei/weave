# Weave

由 AI 驱动的项目、文档与任务协作系统。

用户通过对话澄清需求、形成文档、拆分任务和提出变更，也可以直接编辑正式内容。每次文档或任务变更都需要可追踪，AI 修改必须经过用户确认。

## 当前状态

项目处于设计阶段，尚未初始化应用代码。已确认的核心技术栈为 TypeScript、NestJS、React 和 PostgreSQL。
